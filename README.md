# Daily Task Manager

A simple command-line based task management application built using Python and SQLite.

## Features

- Add new tasks
- View all tasks
- Complete tasks
- Delete tasks
- Search tasks
- Store tasks permanently using SQLite

## Technologies Used

- Python
- SQLite
- SQL

## How It Works

The application provides a simple menu where users can add, view, complete, delete, and search tasks.

All tasks are stored in an SQLite database, so the data remains saved even after closing the program.
